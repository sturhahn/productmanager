# frontend/ index

- `package.json` — scripts: `dev`/`build`/`start`/`lint`/`test` (Vitest, `vitest run`).
- `components.json` — shadcn config: style `base-nova`, aliases `@/components`, `@/lib`,
  `@/components/ui`, icon library `lucide`.
- `next.config.ts`, `tsconfig.json`, `eslint.config.mjs`, `postcss.config.mjs` — standard
  Next.js/TS/lint/Tailwind config, rarely need editing.
- `.env.example` — `NEXT_PUBLIC_API_URL` (API base URL); no secrets live in frontend env.
- `AGENTS.md` — auto-managed by `next dev`; a generic Next.js-version warning, not project
  guidance. Don't hand-edit; regenerated by the framework.
- `CLAUDE.md` — real project guidance (this trio); not managed by Next.js tooling.

## src/app/ — Next.js App Router
- `layout.tsx` — root layout: fonts, `ThemeProvider`, `Providers` wrapper.
- `page.tsx` — redirects `/` to `/roadmap`.
- `login/page.tsx` — single-password sign-in form.
- `globals.css` — Tailwind v4 theme tokens, light/dark CSS variables (incl. `--tier-*` colors).
- `(app)/layout.tsx` — authenticated shell: sidebar + auth-gate redirect.
- `(app)/*/page.tsx` — one route per resource:
  - `roadmap/` — drag/drop timeline to sequence bets and watch team capacity.
  - `initiatives/`, `projects/`, `teams/` — execution-side CRUD screens.
  - `features/` — product capabilities where delivery meets the market.
  - `markets/`, `segments/`, `processes/` — market structure and business-process catalog.
  - `products/`, `competitors/`, `firms/` — market participants and offerings.
  - `coverage/` — gold/silver/bronze grid by business process, us vs. every rival.
  - `channels/` — routes to market: segment reach, opportunity origination, channel bias.
  - `opportunities/` — pipeline of firms seeking coverage for scoped business processes.
  - `assumptions/` — versioned parameter collections with distribution/provenance/rationale.
  - `calibration/` — fits priors to the facts ledger as of a date, shows what moved.
  - `simulate/` — runs and inspects Monte Carlo simulation runs.

## src/components/
- `app-sidebar.tsx` — left nav linking every route, active-path highlighting.
- `market-picker.tsx` — market-context `<Select>` shared by all Market screens.
- `page-header.tsx` — shared title/description/actions header for route pages.
- `providers.tsx` — `QueryClientProvider` + `AuthProvider` + `Toaster` + `TooltipProvider`.
- `confirm-dialog.tsx` — reusable destructive-action confirmation dialog.
- `tier-chip.tsx` — Gold/Silver/Bronze/NotPlaying colored badge.
- `workspace-switcher.tsx` — workspace picker/renamer/creator dropdown.
- `theme-provider.tsx` — thin wrapper around `next-themes`.
- `theme-toggle.tsx` — light/dark toggle using `resolvedTheme`.
- `charts/echart.tsx` — echarts wrapper; re-resolves CSS token colors to rgb per theme (echarts
  can't parse `oklch()`).
- `roadmap/timeline.tsx` — draggable/resizable Gantt bars with feasibility warnings.
- `roadmap/unplanned-tray.tsx` — tray of not-yet-scheduled projects awaiting placement.
- `roadmap/warnings-panel.tsx` — capacity/feasibility warning list for the roadmap.
- `ui/` — 15 shadcn/ui primitives (badge, button, card, checkbox, dialog, dropdown-menu, input,
  label, scroll-area, select, separator, sonner, table, textarea, tooltip). Treat as vendor
  code; regenerate via shadcn CLI rather than hand-patching if you need an upstream change.

## src/lib/
- `api/client.ts` — hand-written typed fetch client, token/workspace stores, `ApiError`.
- `api/types.ts` — hand-written DTO/request TypeScript types mirroring
  `openapi/productmanager.json` (Phase 1 surface).
- `auth.tsx` — single-password JWT auth context (`signIn`/`signOut`/`useAuth`).
- `queries.ts` — all TanStack Query hooks/keys, workspace/market-scoped.
- `market-store.ts` — per-workspace active-market selection, localStorage-backed.
- `calibration.ts` + `calibration.test.ts` — shaping logic for the calibration diff view.
- `coverage.ts` + `coverage.test.ts` — coverage-tier resolution; mirrors
  `SimulationInputBuilder`'s "exact-then-generic" rule (see `CLAUDE.md`).
- `masking.ts` + `masking.test.ts` — mirrors `SimulationInputBuilder.BuildAttractivenessSchedule`
  delta-masking rule.
- `fanchart.ts` + `fanchart.test.ts` — pure math for simulation fan charts/KPI headlines.
- `funnel.ts` + `funnel.test.ts` — firm-level engine opportunity-funnel diagnostics math.
- `pipeline.ts` + `pipeline.test.ts` — groups opportunities into funnel stages vs. sales-cycle
  age.
- `timeline.ts` + `timeline.test.ts` — pure date/geometry math for the roadmap Gantt.
- `process-tree.ts` — depth-first ordering of business processes for indentation.
- `colors.ts` — stable categorical hue assignment for initiatives.
- `utils.ts` — `cn()` clsx/tailwind-merge helper.
