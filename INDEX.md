# Repo index

- `docs/PRDs/product_requirements.md` — the authoritative product spec: vision, domain model,
  phasing, testing posture. Read this before any cross-cutting change.
- `src/ProductManager.Domain/` — entities, value objects, domain services. No EF/API refs.
- `src/ProductManager.Engine/` — pure simulation/calibration library. No project references at all.
- `src/ProductManager.Api/` — ASP.NET Core Web API: the only write path. EF Core + PostgreSQL.
- `src/ProductManager.Cli/` — `pm` CLI: seed loading, entity CRUD, run triggering. HTTP client only.
- `frontend/` — Next.js + TypeScript + shadcn/ui + echarts web app.
- `tests/` — one test project per `src/` project, mirroring names.
- `seed/` — three layered, idempotent JSON seed files (phase1/2/3).
- `openapi/productmanager.json` — the checked-in, self-regenerating OpenAPI contract (generated by
  `dotnet test` against `ProductManager.Api.Tests`; do not hand-edit).
- `scripts/generate-openapi.sh` — convenience wrapper that runs just the OpenAPI-regenerating test.
- `docker-compose.yml` — local Postgres 17 container (port 5433).
- `ProductManager.sln` — solution file referencing every `src/` and `tests/` project.
- `.config/dotnet-tools.json` — pins `dotnet-ef` for migrations.
- `.claude/launch.json` — dev-server launch config for the Claude Code browser preview tool.

For per-directory detail, open that directory's own `INDEX.md`.
